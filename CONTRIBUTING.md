# Contributing

We welcome documentation, tests, issue reports, and small, well-scoped improvements.

1. Open an issue explaining the problem, expected behavior, and a minimal reproducible example.
2. Create a branch and submit a pull request with a clear change summary.
3. Add tests for failure paths and explain any behavior that remains uncertain.
4. Run `npm test` and include the result in the PR description.
5. Do not include real credentials, internal URLs, personal data, private project code, or copyrighted third-party implementations.
6. Maintainers review changes for security, compatibility, test quality, and clarity. Acceptance is not guaranteed.

Good first contributions include adversarial test cases, portable documentation, typo fixes, and structured error examples.

## Code of conduct

Be respectful, focus on technical evidence, and assume good intent. Harassment, personal attacks, and disclosure of another person's private data are not welcome.
